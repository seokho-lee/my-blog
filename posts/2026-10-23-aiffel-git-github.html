아이펠에서 Git과 GitHub를 배운 날

오늘 모두의연구소 아이펠 수업에서 Git과 GitHub를 배웠다. 이름만 많이 들어 봤지 제대로 써 본 적은 없었는데, 직접 해 보니 생각보다 훨씬 재미있었다.

Git과 GitHub는 다르다

가장 먼저 정리된 건 둘의 차이였다.

  • Git은 내 컴퓨터에서 파일의 변경 이력을 관리하는 도구다.
  • GitHub는 그 Git 저장소를 인터넷에 올려 두고 공유하는 서비스다.

로컬에서 Git으로 기록을 쌓고, 그걸 GitHub로 올린다고 생각하니 흐름이 한 번에 이해됐다.

직접 해 본 순서

배운 걸 바로 써 보려고 이 블로그 저장소를 만들었다. 실제로 해 본 순서는 이렇다.

git init
git remote add origin https://github.com/seokho-lee/my-blog.git
git add README.md
git commit -m "Initial commit"
git push -u origin main
  1. git init으로 폴더를 Git 저장소로 만든다.
  2. git remote add origin으로 GitHub 저장소와 연결한다.
  3. git add로 올릴 파일을 고르고, git commit으로 기록을 남긴다.
  4. git push로 GitHub에 올린다.

에러도 배움이었다

한 번에 되지는 않았다. 덕분에 기억에 더 오래 남을 것 같다.

PowerShell에서 && 에러 — Windows PowerShell 5.1은 &&로 명령을 이어 쓸 수 없어서, 명령을 한 줄씩 따로 실행해야 했다.

푸시할 때 인증 실패 — 컴퓨터에 저장된 GitHub 로그인 정보가 맞지 않아서 생긴 문제였다. 저장된 정보를 지우고 다시 로그인하니 푸시가 됐다.

오늘의 한 줄

명령어 몇 줄로 내 컴퓨터의 폴더가 인터넷에 올라가고, 그게 이렇게 블로그가 되는 과정이 신기하고 재미있었다. 앞으로 배우는 것들도 여기에 꾸준히 기록해 보려고 한다.
