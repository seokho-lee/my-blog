# my-blog

공부하고 만들면서 배운 것들을 기록하는 개인 블로그입니다.

## 다루는 주제

- AI · 머신러닝 공부 기록
- 개발하면서 겪은 문제와 해결 과정
- 프로젝트 회고와 생각 정리

## 저장소 구성

빌드 도구 없이 HTML/CSS로 만든 정적 사이트이며, GitHub Pages로 배포합니다.

- `index.html` — 글 목록 (메인 페이지)
- `posts/` — 블로그 글
- `assets/style.css` — 공통 스타일

블로그 주소: https://seokho-lee.github.io/my-blog/
